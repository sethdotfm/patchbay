Patchbay

A hard-edged CSS design system for dense signal-routing and device-control UIs. Square corners, 1px rims, hard offset shadows, one accent.

Plain CSS with no build step and no framework. Light and dark, scaled by the root font size, and WCAG 2.2 AA in both themes. Fonts and icons ship with it, so a UI on a closed network needs nothing from a CDN.

The rules it keeps

One accent
Periwinkle marks selection and focus, nothing else.
Five states
ok, warn, error, info and idle, always with text or an icon.
Amber is unsaved
Commit marks edits waiting to be applied. Warn, the same colour, is device state.
Tokens only
Every colour and size is a --pb-* token. Re-skin by editing one file.
No rounding
Every radius is 0 and every shadow is a hard offset.

Install

npm
npm install patchbay-css
@import "patchbay-css/fonts.css";
@import "patchbay-css";

Serve icons.svg from your own origin: browsers don't load a cross-origin sprite through <use>.

Copy the files

Copy css/, fonts/, icons/ and VERSION into the app, then load:

<meta name="color-scheme" content="light dark">
<link href="fonts/plex.css" rel="stylesheet">
<link href="css/patchbay.tokens.css" rel="stylesheet">
<link href="css/patchbay.css" rel="stylesheet">
